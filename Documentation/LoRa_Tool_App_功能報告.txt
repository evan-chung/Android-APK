【核心功能】

1. BLE 藍牙掃描與連接 ✓
   ├─ 自動掃描附近 BLE 設備
   ├─ 顯示設備名稱和 MAC 地址
   ├─ 實時 RSSI 信號強度顯示
   ├─ 一鍵連接設備
   └─ 連接狀態管理

2. LoRa 數據收發 ✓
   ├─ 發送文本消息
   ├─ 接收消息顯示
   ├─ 消息歷史記錄
   ├─ 時間戳記錄
   └─ 聊天界面

3. LoRa 參數配置 ✓
   ├─ 頻率設定 (433 MHz)
   ├─ 發射功率調整 (dBm)
   ├─ 展頻因子選擇 (SF7-SF12)
   ├─ 帶寬設定 (125/250/500 kHz)
   └─ 快速預設 (3 種模式)

4. 信號監控 ✓
   ├─ RSSI 即時監控
   ├─ 信號強度視覺化
   ├─ SNR 顯示
   ├─ 信號質量評級
   └─ 實時更新 (2 秒間隔)

5. GPS 定位 ✓
   ├─ 位置獲取
   ├─ 緯度/經度顯示
   ├─ 位置歷史記錄
   └─ 位置權限管理

6. 雲端同步框架 ✓
   ├─ 同步功能界面
   ├─ 數據備份選項
   └─ 同步狀態顯示

1. 打開應用

4. 點擊「開始掃描」
5. 選擇要連接的設備
6. 進入「數據」頁面收發消息
