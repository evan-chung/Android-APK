📲 安裝方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方法 1】USB 安裝 (推薦)
─────────────────────────────────────────────────────────

1. 手機設定:
   • 進入「設定」→「開發者選項」
   • 啟用「USB 調試」
   • 連接 USB 線到電腦

2. 電腦執行:
   PowerShell:
   $adb = "C:\Users\user\AppData\Local\Android\Sdk\platform-tools\adb.exe"
   & $adb install "C:\Users\user\.qclaw\workspace\LoRaToolApp2\android\app\build\outputs\apk\debug\app-debug.apk"

   或直接雙擊運行: install.bat (如果存在)

3. 等待安裝完成 (約 30-60 秒)

【方法 2】文件傳輸安裝
─────────────────────────────────────────────────────────

1. 複製 APK 文件:
   C:\Users\user\.qclaw\workspace\LoRaToolApp2\android\app\build\outputs\apk\debug\app-debug.apk

2. 傳輸到手機:
   • USB 線連接 → 複製到 Downloads 資料夾
   • 或通過微信/Line 傳輸

3. 手機上安裝:
   • 打開文件管理器
   • 進入 Downloads 資料夾
   • 點擊 app-debug.apk
   • 點擊「安裝」

【方法 3】ADB 無線安裝
─────────────────────────────────────────────────────────

1. 手機和電腦連接同一 WiFi

2. 執行:
   $adb = "C:\Users\user\AppData\Local\Android\Sdk\platform-tools\adb.exe"
   & $adb connect <手機IP>:5555
   & $adb install "C:\Users\user\.qclaw\workspace\LoRaToolApp2\android\app\build\outputs\apk\debug\app-debug.apk"

🚀 首次使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 打開 APP
   • 點擊手機上的「LoRa Tool」圖標

2. 授予權限
   • 藍牙權限 (BLUETOOTH_SCAN, BLUETOOTH_CONNECT)
   • 位置權限 (ACCESS_FINE_LOCATION)
   • 點擊「允許」

3. 掃描設備
   • 進入「掃描」頁面 (📡)
   • 點擊「開始掃描」按鈕
   • 等待 5 秒搜索附近的 BLE 設備

4. 連接設備
   • 點擊要連接的設備
   • 等待連接成功提示

5. 收發數據
   • 進入「數據」頁面 (💬)
   • 輸入消息
   • 點擊「發送」

6. 監控信號
   • 進入「監控」頁面 (📊)
   • 實時查看 RSSI 信號強度

⚙️ 配置 LoRa 參數
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

進入「配置」頁面 (⚙️):

• 頻率: 433 MHz (標準 LoRa 頻率)
• 功率: 20 dBm (最大發射功率)
• 展頻因子 (SF):
  - SF7: 高速傳輸 (短距離)
  - SF9: 平衡模式
  - SF12: 長距離傳輸 (低速)

快速預設:
• 長距離: 433MHz / 20dBm / SF12
• 平衡: 433MHz / 17dBm / SF9
• 高速: 433MHz / 14dBm / SF7

❌ 常見問題
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 安裝時提示「無法安裝」
A: 
   • 確保手機有足夠存儲空間 (至少 100MB)
   • 檢查是否允許安裝未知來源應用
   • 設定 → 安全 → 允許安裝未知應用
   • 嘗試卸載舊版本後重新安裝

Q2: 掃描不到設備
A:
   • 確保藍牙已開啟
   • 確保目標設備已開啟並在藍牙模式
   • 檢查位置權限是否已授予
   • 嘗試重新啟動藍牙

Q3: 連接失敗
A:
   • 確保設備在有效範圍內 (通常 10-100 米)
   • 檢查設備是否已被其他應用連接
   • 嘗試重新掃描
   • 重啟手機和設備

Q4: 無法發送數據
A:
   • 確保設備已連接 (首頁顯示連接狀態)
   • 檢查設備是否支持該 BLE 服務
   • 查看設備的 UUID 配置
